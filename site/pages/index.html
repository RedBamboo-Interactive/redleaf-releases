Your project

Nova keeps the whole project in her head.

You decide what the project should become. Nova turns that into jobs, hands each one to a coding session, checks the result, and keeps the roadmap, the decisions and the history in her memory.

{{icon:game-controller}}

A video game

Mechanics, levels, menus, and the bug that only happens on the second jump. Nova keeps the design notes and the to-do list, and can make the art and the voices too.

{{icon:device-mobile}}

An app

From the first screen to a build you can hand to friends. Features move forward side by side, with the tests run on every change.

{{icon:globe-simple}}

A website

A portfolio, a shop, a page for your band. Describe it, see it running on your own computer, and change it in plain words.

What it's for

Bring a project. Leave with the thing made.

Other agents run errands in the cloud. RedLeaf is for making things: the project first, and the art, sound, plans and knowledge around it, made on your machine and kept there. Open the cookbook {{icon:arrow-right}}

{{recipes}}

What you install

Four apps that know about each other.

RedLeaf is one local service with its apps inside. They share the same agents, files and history, so work can move between them without copy and paste.

{{icon:star}}

Nova

Your main agent and the one you talk to. Keeps parallel discussions, a Live timeline, and a heartbeat that checks on things for you.

  • Discussions per topic
  • Several agents, each with a personality
  • Voice in and out
{{icon:terminal-window}}

Code

Persistent coding sessions on your repositories. Nova can start one, follow it, review the result and continue it later.

  • Sessions that survive restarts
  • Commits, issues and tests per repository
  • Access levels from Plan to Full
{{icon:folder-simple}}

Workspace

Every agent's files and memory as pages you can open, edit and link. Also mounted as a real folder on your disk.

  • Memory that outlives a chat
  • Pages, entities and links
  • A drive on Windows, ~/Leaf on Linux
{{icon:cpu}}

Compute

Where models run. Chat, speech, images and music go through one engine, with every job visible and every provider swappable.

  • Hosted and local providers
  • Text, speech, image and music
  • A job list you can inspect

How it is built

It runs on your machine, and you can see what it does.

{{icon:house}}

Local first

RedLeaf, its database and every agent workspace live on your computer. Your conversations are stored there; RedBamboo never receives them.

{{icon:lightning}}

Your providers

Connect the AI accounts you already use, or run local models for speech and images. Prompts go to the provider you choose, under that provider's terms.

{{icon:shield-check}}

Signed updates

The launcher and every component are checked against a signed release feed and a SHA-256 hash before they run. Nothing unverified is installed.

{{icon:eye}}

Visible work

Every agent job appears in Compute, every Code session keeps its transcript, and every memory is a page you can read and correct.

Download

Install RedLeaf.

Setup installs the suite, prepares the agent workspace and walks you through your account and your first AI provider. It takes a few minutes.

  1. 01

    Run the installer

    On Windows, RedLeaf Setup. On Linux, the one-line install in a terminal, as yourself.

  2. 02

    Approve the agent filesystem

    Windows asks once for administrator approval to install WinFsp. Linux uses FUSE 3, which you install beforehand.

  3. 03

    Create the local owner

    Your RedLeaf account and the agent workspace stay on this machine.

  4. 04

    Connect an AI provider

    Pick a provider, finish its sign-in, and open your first discussion with Nova.

Before you install. RedLeaf needs FUSE 3 for your ~/Leaf folder: sudo dnf install fuse3 on Fedora, sudo apt install fuse3 on Debian and Ubuntu. It runs with SELinux enforcing; there is nothing to relabel or turn off. It installs into your home folder and checks the launcher against the signed release record before running it.

Requirements and dependencies

Windows x64 or Linux x64

Linux is tested on Fedora with SELinux enforcing.

FUSE 3 on Linux

Provides your ~/Leaf folder. Install the fuse3 package first.

Administrator approval on Windows

Needed once for WinFsp, which provides agent workspace drives.

An AI provider account

Use the sign-in flow of the supported provider you choose.

Git

Needed when Code works with local repositories: Git for Windows, or your distribution's git package. RedLeaf does not install Git.

Internet access

To download components and reach your AI provider.
