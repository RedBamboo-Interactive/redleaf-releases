Keyboard shortcuts.

The shortcuts that save the most time, in one place. Menus show the shortcut next to each item for the discussion or session that's open.

Discussions and sessions

KeysAction
Ctrl+NNew discussion in Nova, new session in Code
Alt+↓ / Alt+↑Next / previous discussion or session
Ctrl+Shift+FSearch every discussion, or every session
Alt+IInfo: provider, model, cost, access level
Alt+AArtifacts shared in the conversation
Alt+RRename
Alt+TWrite a title from the conversation
Alt+SShare a read-only copy
Alt+WClose: stop and archive
Alt+VVoice mode
Alt+Shift+LReset the Live timeline
Ctrl+Alt+NOpen Float Nova

The composer

KeysAction
EnterSend. While the agent works: queue for after this turn, or join the turn with providers that support it.
Shift+EnterNew line
TabQueue instead of joining the turn, with providers that support joining
Ctrl+EnterInterrupt and send now
EscInterrupt the agent
Shift+TabPlan mode on and off, in Code
Push-to-talk keyHold to talk. Set it in Settings › Nova › Voice.
