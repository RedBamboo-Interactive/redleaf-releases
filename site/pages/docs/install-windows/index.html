Get started

Install on Windows.

RedLeaf installs for your Windows account, with no installer wizard and no service. The launcher checks every download against the signed release feed, installs the suite, and opens it in your browser.

Before you start

  • Windows x64. ARM devices are not supported yet.
  • Internet access, to download the components and to reach your AI provider.
  • An AI provider you can sign in to, such as a Claude subscription for Claude Code or a ChatGPT account for Codex. See AI providers.
  • Git for Windows, only if you want to use Code on your own projects. RedLeaf does not install Git.

You don't need a graphics card. One is only needed if you later add local models for images or voice.

Install

  1. Download the launcherGo to the download section and choose Download Nightly. The file name starts with redleaf-launcher. To check it, choose Show SHA-256 and compare the hash with the one Windows gives you for the file (Get-FileHash in PowerShell).
  2. Run it as yourselfDouble-click the file. If SmartScreen says “Unknown publisher”, choose More info, then Run anyway. Don't run it as administrator: RedLeaf installs for your account and restarts itself without administrator rights if you do.
  3. Let it installThe launcher reads the signed release feed, verifies each component's signature and hash, installs the suite and starts it. When it is ready, your browser opens RedLeaf at http://127.0.0.1:18804.
  4. Approve WinFsp onceSetup's first step installs WinFsp, which gives your agents their workspace drive. Windows asks for administrator approval for that one installation. See Set up RedLeaf for the rest.

Where it lives

WhatWhere
The program%LOCALAPPDATA%\RedLeaf-Suite
Your data%LOCALAPPDATA%\RedLeaf: settings, the private database, logs and backups
Agent workspacesDrive L:, under L:\Workspaces, while RedLeaf runs
Scratch spaceDrive S:, cleaned up automatically after 30 days
Start menuA RedLeaf entry. No desktop shortcut is created.

Opening, closing and starting with Windows

RedLeaf keeps running in the notification area after you close the browser tab. Its tray icon has Open RedLeaf, an Apps menu with one entry per app, Start with Windows, Restart and Exit. To open it later, use the Start menu or the tray icon; starting it a second time just tells you it is already running.

To pin it, open Start, search for RedLeaf, right-click it and choose Pin to taskbar. To start it when you sign in, turn on Start with Windows in the tray menu or in Settings › System.

{{icon:lightbulb}}

Keep the launcher. Running the downloaded file again on a machine where RedLeaf is installed repairs the installation and keeps your choices. Updates themselves are installed from inside RedLeaf: see Updates.

If something goes wrong

  • The download button says it is unavailable. The site could not reach the signed release feed. It never offers an unverified file instead, so try again a little later.
  • Windows keeps running it as administrator. Right-click the file, open Properties › Compatibility, untick “Run this program as an administrator”, and run it again.
  • It started, then stopped. The launcher's log is at %LOCALAPPDATA%\RedLeaf\update\logs\launcher.log. See Troubleshooting.
