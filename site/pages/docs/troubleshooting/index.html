Troubleshooting and Doctor.

Most problems show up in one of three places: the recovery screen when RedLeaf can't start, Setup & Health when something it depends on isn't right, or a provider that stops answering. Here's what each one means and what to do.

Check health first

Open Settings › Setup & Health. It runs live checks on RedLeaf's core services, its capabilities and access, and says All systems healthy or System needs attention, with the failing checks and why. Choose Run health checks again after fixing something.

RedLeaf won't start

If RedLeaf can't finish starting on an existing installation, it shows Recover RedLeaf instead of setup. It says what failed, in plain words, and what happened to your data. For example, that it couldn't reach the database and so hasn't read or changed anything in it.

  • Try again reruns the whole start. A database update can take several minutes.
  • Open log folder opens the logs, one file per day.

Don't reinstall RedLeaf or delete its data folder to get past this screen. Your installation is still there, and setup doesn't need to run again. If Try again doesn't help, ask in #bug-reports on the Leaf Discord with the newest log file and a screenshot of the page.

Common problems

You seeWhat to do
“RedLeaf is already running.”It's in the notification area. Use the tray icon's Open RedLeaf.
“Server failed to start”Another program is using RedLeaf's port, 18804. Close it and start RedLeaf again.
“Drive L: is already in use”Another drive or program has taken the workspace letter. Free it, or pick another Workspace drive in Settings › Storage › Workspaces.
The launcher asks you to disable “Run this program as an administrator”Untick it in the file's Properties › Compatibility, and run it again as yourself.
“must not run as root” on LinuxRun the installer or launcher again without sudo.
“The FUSE runtime is missing”Install fuse3 from your distribution, then Try again.
Claude Code: “Installed, not signed in.”Sign in again from the provider's settings in Settings › Extensions. If RedLeaf can't find Claude Code at all, install it, or enter its location in the extension's advanced settings.
Codex won't install on LinuxRun curl -fsSL https://releases.openai.com/codex/install.sh | sh, then choose Check again.
“Session paused”, usage limit reachedYour provider's limit. Send a message after it resets and the session continues.
A capability shows a purple moon in ComputeIt's asleep, so its requests are frozen. Press the moon button to wake it.
An update failedIt was rolled back. The reason is in the launcher log, update/logs/launcher.log in RedLeaf's data folder.

Doctor

Doctor is a repair kit that keeps working when RedLeaf itself doesn't. It's a separate page in your browser with health checks, Restart suite, and repair sessions where Claude Code or Codex can diagnose and fix the installation with you. It's installed with RedLeaf and starts with it. Doctor is on Windows only for now.

Set it up now, while everything works:

  1. Create its access tokenIn Doctor's settings, under Access, choose Rotate and keep the token in your password manager. It's shown once.
  2. Bookmark itOpen http://127.0.0.1:18899 and bookmark it.
  3. Pick its AIUnder Repair sessions, choose Claude Code or Codex.
  4. Decide on unrestricted repairIt's on by default: the repair session may act without asking at each step. Turn it off if you'd rather approve each one.

Doctor is only reachable from your computer. If its page won't open, check that Doctor is on and its port is free, and use Restart Doctor in its settings. If you lost the token, rotate it again; that needs RedLeaf running.
