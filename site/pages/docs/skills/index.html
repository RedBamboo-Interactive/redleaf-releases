Going further

Skills and protocols.

A skill is a package of know-how an agent can pick up when it's relevant: how to review a pull request, how your release works, how to talk to your smart home. Write it once and give it to any agent. Protocols are the short version: a rule of conduct shared between agents.

What a skill is

FieldWhat it's for
DescriptionWhen the skill applies. The agent reads this to decide whether to open the skill, so make it specific. Up to 1,024 characters.
InstructionsThe skill itself, in Markdown: steps, rules, examples, pitfalls.
Package filesOptional extra files: scripts, templates, reference tables.
Icon, TagsTo find it in the library and the agent picker.
TrustYour review of executable or imported content.
AgentsWhich agents use it.

Skills are entities of the type Agent Skill, in Database › Entities. Open one to edit its instructions, or its Package files to upload files and Save package.

Give a skill to an agent

On the agent's page, add it to the Skills field. RedLeaf places a read-only copy in the agent's workspace, in the format its AI provider expects, and keeps it current when you edit the skill. Don't edit those copies: change the skill and they follow.

Extensions can bring skills of their own. When you install one that does, RedLeaf asks which agents to Give this skill to, with Nova preselected.

Writing a good skill

  • Write the description as a trigger: “Use when reviewing a pull request in this repository”, not “PR stuff”.
  • Keep one job per skill. Two narrow skills beat one that covers everything.
  • Say what to check, not just what to do. Agents follow acceptance criteria well.
  • Put facts that change in memory, and procedures in skills.

Nova's skills

Nova starts with skills for working inside RedLeaf, engineering, delegating to Code, embedding RedLeaf items in a reply, and the three dreaming skills that consolidate her memory overnight. Remove any of them from her Skills field if you don't want that behaviour.

Protocols

A protocol (an Agent Protocol entity) is a short conduct rule, up to 1,500 characters, added to an agent's instructions after its Output Protocol. Use one for a rule several agents should share. Nova's default protocol covers emoji reactions: she reacts from time to time, the way a person in a chat would, and never uses a reaction in place of answering something personal. Add protocols to an agent in its Protocols field.

Heartbeat skills

An agent with Live on has a separate Heartbeat Skills field: what its heartbeat ticks may do. Every tick carries them in full, so each must stay under 1,500 characters and point to a full skill for anything longer. Ones that are too long or empty are refused with a reason. See Schedules and the heartbeat.
