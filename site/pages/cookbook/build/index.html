A simplified recreation of RedLeaf. The project is an example.

What you can ask

  • Start a small web app that tracks my climbing routes. Plain HTML, with tests.
  • The login page breaks on mobile Safari. Find out why and fix it.
  • Read the open issues on GitHub and tell me which three are worth doing this week.
  • Review what the last session changed before I merge it.

How it works

  1. Register a repositoryOpen Code and add a folder that is a Git repository, or let Nova create a new one for you. Code shows its branch, commits, issues and tests.
  2. Ask NovaDescribe the change the way you would to a colleague. Nova writes the brief for the session and says what she expects back.
  3. A Code session does the workIt reads the code, edits files, runs commands and tests at the access level you allow. You can open the session at any time and watch or step in.
  4. Nova reports backWhen the session finishes, Nova reads the result, checks it against what you asked, and tells you in the same discussion. Ask for changes and she continues the same session.
{{icon:shield-check}}

You decide how far it goes. Each session runs at an access level: Plan only reads, Ask checks with you before commands, Auto decides what is safe, and Full is off until you turn it on.

What you need

GitGit for Windows, or your distribution's git package.
A coding providerFor example Codex or Anthropic, connected during setup.
GitHub CLI, optionalFor issues, pull requests and pushing to GitHub.
