A simplified recreation of RedLeaf. The project is an example.

What you can ask

  • Start a small app for my climbing gym: routes, grades, and a button to mark one as sent.
  • For the game: a level select screen, controller support, and make the jump less floaty.
  • My website looks broken on phones. Find out why and fix it.
  • What's left before the demo is ready? Put it in order.

Several things at once

Ask for three things and Nova can start three sessions. Each one works on its own branch: a separate copy of the project where it can be built and tested without disturbing the others. When a piece works, Nova merges it into the real project. When it doesn't, it never touches it, and you can look at it, change it or drop it.

You choose the branch when you start a session, or let Nova pick a name. RedLeaf sets up the separate copy for you, and Code shows which branches are ahead, which are merged and which still have unsaved work.

Watch every step

Everything an agent does appears as a small square in the conversation, in the order it happened. A square wobbles while the step is running. Click any square to see exactly what was done: the file it opened, the change it made, the command it ran and what came back.

How it works

  1. Bring your projectPoint Code at the folder of an existing project, or ask Nova to start a new one. Code shows its history, open issues and tests.
  2. Say what you want nextIn plain words, the way you would brief a friend who codes. Nova writes the instructions for each session and says what she expects back.
  3. Sessions do the workThey read the code, make the changes, run the tests and save the result, at the access level you allow. Open any session to watch or step in.
  4. Nova checks and reportsWhen a session finishes, Nova reviews it against what you asked, merges what's ready, and tells you what needs your eyes. Ask for changes and she continues the same session.
  5. The project is rememberedThe roadmap, decisions and history live in Nova's memory, so next week's conversation starts where this one ended.
{{icon:shield-check}}

You decide how far it goes. Each session runs at an access level: Plan only reads, Ask checks with you before commands, Auto decides what is safe, and Full is off until you turn it on.
