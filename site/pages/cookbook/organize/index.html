What you can ask

  • Sort everything in Inbox by type and year, and tell me what you couldn't place.
  • Keep a page of every decision we make on this project, with the date and the reason.
  • What did we decide about the logo last month?
  • That note is wrong, the deadline moved to Friday. Fix it everywhere.

How it works

  1. Each agent has a workspaceIt holds the agent's memory, configuration and files. Open it in the Workspace app, or as a drive on Windows and ~/Leaf on Linux.
  2. Memory is pages, not a black boxWhat an agent remembers is written as pages you can read. If something is wrong, edit it and the agent works from your version.
  3. Structure when you want itPages can link to each other and to entities such as repositories, people or projects, which you can browse and filter in Database.
  4. It carries overStart a new discussion next week and the agent still knows the project, because it reads its workspace rather than a chat log.
{{icon:house}}

Your files stay yours. The workspace lives on your computer. Content only leaves it when an agent sends it to the AI provider you chose, in order to read or write it.

What you need
