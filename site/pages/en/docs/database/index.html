Going further

Database and views.

Under the apps, everything in RedLeaf is an entity: pages, agents, skills, repositories, automations, and anything you define yourself. The Database app shows all of it, lets you create your own types, and searches across everything at once.

Entities and types

Every entity has a type, and every type has fields. A Character type for your game might have a name, a portrait, a faction and a list of quests. Agents can read and fill these just like you, which is how a project's structure stays shared between you and them.

  1. Open DatabaseFrom the app switcher, then Entities. The list shows every Entity Type, organised in folders. RedLeaf's own types sit in the locked System section, and the Scope filter narrows the list to one app or workspace.
  2. Create a typeChoose New type and name it, for example Document, Character or Item.
  3. Add fieldsIn the type's fields, add what it needs and choose Save Changes.
  4. Add entitiesUnder Instances, choose New. Or ask an agent to fill them in from your notes.

Field types: String, Number, Float, Boolean, Date, Select, Multi Select, Entity Ref, Entity List, Media, Color, JSON and Markdown. Entity Ref and Entity List link entities together, such as a quest to its characters.

Search

Database › Search is one search across everything you're allowed to read. Search in Entities (names, properties and references) or in Records (pages, discussions, sessions and other indexed streams). Narrow it by entity type, by the field to match, or by date. Results respect permissions, so each person only finds what they can see.

Views in your projects

In a Workspace project, New view shows a set of entities in a layout of your choosing. Give it a name, pick the entity type and a display mode, and choose Create View.

ModeWhat you get
BoardColumns grouped by a select field, such as a status. Drag a card to another column to change the field.
ListA vertical list, optionally grouped by a field.

A board grouped by status is a roadmap: the agent can move cards as work moves, and you see the same board.

Pages

A Workspace project is a page, and pages nest. Open one to write in it, pin the items you use most under Structure, and choose Share to create a link to it. Every change is versioned, with Undo this change in its history.

Roles

RedLeaf has three roles: Admin, with full access including settings; Editor, who can read and write all content but can't manage users or roles; and Viewer, with read-only access. The owner account created at setup is an admin. More people need Google sign-in: see Remote access.
