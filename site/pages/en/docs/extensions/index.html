Going further

Extensions.

Everything beyond the core comes as an extension: providers, new apps such as Smart Home or Gallery, and connections such as Discord or Mail. You find, install and manage them in one place, and every one is signed.

Where to find them

Open Settings › Extensions. Search across what's installed and the Marketplace at the top. The list is grouped:

GroupWhat's in it
CoreParts RedLeaf manages itself, such as Nova, Code and Compute. Always available.
System companionPrograms that run independently of RedLeaf, such as Doctor.
InstalledExtensions you added. Each has a switch to turn it off without uninstalling.
MarketplaceEverything available from the signed release feed.

Installed extensions with settings also get their own entry in the Settings sidebar.

Before you install: the guide

Open any extension to read its Guide: what it does, what you'll need, setup, things to try, privacy and cost, limits, and what to do if something's wrong. The Marketplace card also says whether it fits your machine, for example Works on this PC, Needs WSL or Needs an NVIDIA GPU. Not sure? Choose Ask Nova about this.

Install, turn off, uninstall

  • Install from its Marketplace entry. Installing needs the admin role, which the owner account has. Some extensions then ask you to Finish setup, such as signing in or saving a key.
  • Turn off an installed extension with its switch.
  • Uninstall from More actions › Uninstall. If other extensions depend on it, RedLeaf tells you and doesn't remove it.

Some changes take effect after a restart. RedLeaf shows Changes pending restart and offers to restart, which takes a few seconds.

Agents can suggest an extension by linking to it, but they never install one themselves.

Capabilities and providers

Some extensions are capabilities: a shared base such as Text to Speech or Image Generation, which does nothing on its own. Providers fill them in. You rarely install a capability yourself; it comes with the first provider that needs it. When several providers fill the same capability, pick the Default provider in the capability's settings. See AI providers and local models.

Updates

Extension updates come from the signed release feed, like the rest of RedLeaf. The Extensions section shows when updates are available; choose Review updates to install them from Updates.
