Uninstall and your data.

Uninstalling removes the program and keeps your data, so you can come back later and find everything where you left it. Deleting the data too is a separate, deliberate step.

Uninstall

RedLeaf is removed with its launcher, the same file you installed it with. Use a downloaded copy of the launcher, not the one inside the installation.

Windows

Open PowerShell in the folder where you downloaded the launcher, for example Downloads, and run it with uninstall:

.\redleaf-launcher-<version>-<build>-win-x64.exe uninstall

Use the full name of the file you downloaded; it starts with redleaf-launcher.

If you no longer have it, download it again from the download section.

Linux

Download the Linux archive from the download section, extract the launcher, and run:

tar -xzf redleaf-linux-x64.tar.gz redleaf-launcher
./redleaf-launcher uninstall

The launcher stops RedLeaf, then removes the installed program, its update state and the Start menu or applications menu entry. On Linux, it also unmounts ~/Leaf.

What stays

Your data is kept: settings, the private database with your discussions, agents and memory, encryption keys, assets and backups. Reinstall later and RedLeaf picks it up again.

WhatWindowsLinux
Settings, database, logs, backups%LOCALAPPDATA%\RedLeaf~/.local/share/RedLeaf
Encryption keys%LOCALAPPDATA%\RedSuiteunder ~/.local/share
The program (removed)%LOCALAPPDATA%\RedLeaf-Suite~/.local/share/RedLeaf-Suite

Agent workspaces on L: or in ~/Leaf aren't separate files: they're a view of pages in the database, and they disappear when RedLeaf isn't running.

Deleting your data

{{icon:warning}}

This can't be undone. Deleting these folders removes every discussion, agent, memory and backup stored in them. If you might want any of it, keep a copy first, or keep your off-site copy and its recovery passphrase.

After uninstalling, delete %LOCALAPPDATA%\RedLeaf and %LOCALAPPDATA%\RedSuite on Windows, or ~/.local/share/RedLeaf on Linux. WinFsp, installed during setup, is a separate program: remove it from Settings › Apps in Windows if nothing else uses it.

Data held by your AI providers, such as conversation history in your provider account, is governed by them. RedLeaf can't delete it for you.

If you turned on anonymous usage statistics, Delete my data in Settings › Usage sharing removes what was sent, as described in the usage statistics notice. Do it before uninstalling.
