Going further

AI providers and local models.

RedLeaf doesn't come with a model of its own. Each ability, from chat to images, is filled by a provider you choose. Some run in the cloud on your own account; others run on your graphics card, for free.

These do your agents' thinking. RedLeaf installs all three, and you sign in to at least one during setup.

Sign-ins stay with each provider's own tool on your PC. If RedLeaf can't find Claude Code in an unusual place, enter its location in the extension's advanced settings. By default Codex may only change files in its working folder; that's its Sandbox mode.

Quality tiers instead of model names

You don't pick model IDs. You pick a quality tier, and each provider maps it to its own models:

TierGood for
FastQuick answers, quizzes, small chores
StandardMost work, including coding sessions
DeepHarder problems that deserve more thinking
ResearchLong, careful investigations

Each agent has a default Provider and Quality Tier. Override them when you start a discussion or session, or change them later in Info, which restarts the session.

Local models

Local providers are set up for you. RedLeaf prepares the environment, downloads the program and its models, starts it, and tests it with a small job. The first start can take several minutes. Voice and transcription run inside WSL 2 on Windows. ComfyUI runs natively, and can adopt an installation you already have if you point it at the folder. RedLeaf starts ComfyUI when it's needed, so you never open it yourself.

The Marketplace card tells you before you install whether it fits your machine: Works on this PC, Needs WSL, Needs an NVIDIA GPU, or how much graphics memory or disk space is missing.

Keys and privacy

API keys you save are encrypted in RedLeaf's own store and are never shown again or sent to the browser. Keys you give to Codex go straight to Codex. Content only leaves your computer when an agent sends it to the provider you chose, so your choice of provider decides what leaves. Local providers send nothing out.

Watching usage

Compute shows every job and its cost, and Compute › Stats adds totals, success rates and token counts over time. Where a provider reports a subscription quota, a thin ring around the Live discussion's avatar shows how much is left: teal, then gold from 90% used, red at the limit. Hover it for a summary.
