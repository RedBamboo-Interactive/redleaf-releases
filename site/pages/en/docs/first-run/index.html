Get started

Set up RedLeaf.

The first time RedLeaf opens, it prepares its private storage on its own, then walks you through six short chapters. Most take one click. Two need you: your account and your AI provider.

Prepare RedLeaf

Before the chapters, RedLeaf prepares two things that stay on your machine. You'll see their progress under Prepare RedLeaf, and the first chapter opens when both are ready.

  • The agent filesystem. On Windows, RedLeaf downloads and verifies WinFsp, then shows Windows needs your approval: approve the installation prompt. On Linux, it tests a disposable FUSE mount as your user. If FUSE is missing, install the fuse3 package and choose Try again.
  • The private database. RedLeaf downloads and starts its own PostgreSQL. You don't need Docker or an existing server. This can take a few minutes on the first launch.

If a step fails, choose Try again. It's safe to retry.

{{icon:warning}}

Stuck on Windows error 1005? If Verifying the agent filesystem fails with GetFinalPathNameByHandleW failed with Windows error 1005, WinFsp needs Windows to restart before it works. Restart Windows and open RedLeaf from Start: preparation picks up where it left off.

The six chapters

Use Back and Next to move between them. A chapter unlocks when the one before it is done.

ChapterWhat you do
WelcomeNothing to fill in. It lists what setup unlocks: a private workspace, a connected AI, and Nova, ready to work.
AppearanceChoose light or dark and high contrast. You can change both later in Settings › Appearance.
Available from StartOn Windows, how to find RedLeaf in Start and pin it. On Linux this chapter is Launch RedLeaf: how to start and stop it, and where your data lives.
Your RedLeaf spaceCreate the local owner account: display name, email and a password of at least 8 characters. Choose Create my account. RedLeaf restarts once and continues.
Connect AIChoose the provider Nova will use, sign in, and verify it. See below.
Meet NovaYour first short conversation. Then choose Complete setup.

Your password is used only to create the account. It never enters setup progress, logs or Nova's profile. You can add Google sign-in later, for remote access or more people: see Remote access.

Connect AI

RedLeaf lists the providers it finds on this computer and preselects one: Claude Code first, then Codex. Each one signs in through its own app or command line, in your browser:

ProviderHow you sign in
Claude CodeContinue with Claude for a Claude subscription, or Use Anthropic Console for API billing. Claude Code must already be installed.
CodexContinue with ChatGPT, or Use an API key. If Codex isn't installed, choose Install Codex CLI: RedLeaf installs OpenAI's package for your account, without administrator rights.
OpenCodeOpen OpenCode sign-in opens a terminal where you pick a provider and sign in. You install OpenCode yourself.

Then choose Verify. RedLeaf sends one harmless request to prove Nova can use the provider. If you installed or signed in somewhere else in the meantime, choose Check again.

If RedLeaf says the Claude Code CLI was not found although you installed it, its folder is probably missing from your PATH. Claude Code's installer puts it in %USERPROFILE%\.local\bin. Add that folder to your user PATH, choose Exit in RedLeaf's tray menu, open RedLeaf again from Start, and choose Check again.

{{icon:shield-check}}

Your sign-in stays with the provider. Claude Code and Codex keep their own credentials on your PC. An API key you paste is handed to the provider's tool, and anything RedLeaf does store is encrypted.

Meet Nova

The last chapter opens a small chat with Nova. Say hello. If her greeting can't start, choose Try again. You'll also see a switch to share anonymous usage statistics: counts such as how many sessions ran, never what was in them. It is off unless you turn it on, and you can change it later in Settings › Usage sharing. The usage statistics notice lists exactly what is sent.

Complete setup becomes available once the workspace is mounted and Nova has answered. RedLeaf then opens Nova, with your first discussion waiting.

Changing your answers later

Everything here can be changed in Settings. To walk through setup again, open Settings › Setup & Health and choose Revisit setup.
