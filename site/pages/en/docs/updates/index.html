Going further

Updates.

RedLeaf checks for updates on its own and tells you what's ready, but nothing installs until you choose it. When you do, it waits for running work, restarts, checks that everything is healthy, and rolls back if it isn't.

Installing updates

  1. Get toldRedLeaf checks at startup and then every 12 hours. When something is ready, a notice says Update available, with Open Updates.
  2. Save your workAn update restarts RedLeaf. Make sure nothing important is in the middle of running.
  3. UpdateIn Settings › Updates, choose Update all to install everything with one restart, or Update on one component. Check now looks again straight away.

After you start it, RedLeaf waits for active AI and automation work to finish, restarts through the launcher, verifies its health, and puts the previous version back if the new one fails. A component can update on its own when it doesn't depend on the others.

Channels

RedLeaf is a Nightly preview: new builds are published automatically when something changed, and they can change often. During the preview, releases are published on the Nightly channel only, so keep Channel on Nightly. Under Advanced you can set Component channels or Exact version pins for single components, and Save changes. Most people never need to.

How downloads are verified

Every component comes from the signed release feed. RedLeaf checks the signature on each release record and the SHA-256 hash of each file, and rejects an older record replayed as new. The keys it trusts are built into the launcher. If anything doesn't match, nothing is installed. There is never an unverified fallback.

Repairing an installation

On Windows, running the launcher you downloaded again repairs the installation and keeps your choices. On Linux, update from inside RedLeaf; running the installer again just opens the existing installation.

If an update fails and rolls back, the launcher's log explains why: %LOCALAPPDATA%\RedLeaf\update\logs\launcher.log on Windows, under ~/.local/share/RedLeaf/update/logs on Linux. See Troubleshooting.

Extension updates arrive the same way and install from the same page.
