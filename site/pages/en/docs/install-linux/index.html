Get started

Install on Linux.

RedLeaf installs into your home folder, as you, with no root access. A short script checks the launcher against the signed release record, and the launcher checks everything else before it installs.

Before you start

  • Linux x64. RedLeaf is tested on Fedora with SELinux enforcing. There is nothing to relabel or turn off.
  • FUSE 3, which provides your ~/Leaf folder. Install it first: 
    # Fedora
sudo dnf install fuse3
# Debian and Ubuntu
sudo apt install fuse3
# Arch
sudo pacman -S fuse3
  • The usual tools: curl, tar, sha256sum, python3 and mktemp. Most distributions have them already.
  • An AI provider you can sign in to. See AI providers.
  • Git from your distribution, only if you want to use Code on your own projects.

Install

  1. Copy the commandGo to the download section, choose the Linux tab and copy the install command. It looks like curl -fsSL https://…/install.sh | sh and always points at the current signed release.
  2. Run it as yourselfPaste it into a terminal. Don't use sudo: RedLeaf installs per user and refuses to run as root.
  3. Watch it check and installThe script reads the signed feed, downloads the launcher, and checks its exact size and SHA-256 against the signed record. Nothing runs if they don't match. The launcher then verifies the feed again and installs the suite.
  4. Open RedLeafYour browser opens http://127.0.0.1:18804. On a machine without a display, such as over SSH, the launcher prints the address instead. Continue with Set up RedLeaf.

Prefer not to pipe a script into a shell? Choose Download Nightly on the Linux tab instead, compare the archive with Show SHA-256, then:

tar -xzf redleaf-linux-x64.tar.gz redleaf-launcher
./redleaf-launcher open
{{icon:warning}}

The Linux release may not be out yet. If the Linux tab says the Linux release is not published, there is nothing to install for now. Windows releases are published separately.

Where it lives

WhatWhere
The program~/.local/share/RedLeaf-Suite
Your data~/.local/share/RedLeaf: settings, the private database and logs. Back up this folder to keep everything.
Agent workspaces and your projects~/Leaf/Workspaces and ~/Leaf/Projects, while RedLeaf runs
Menu entryRedLeaf in your applications menu

If XDG_DATA_HOME is set, RedLeaf uses it instead of ~/.local/share.

Starting and stopping

Start RedLeaf from your applications menu. There is no tray icon on Linux, and RedLeaf keeps running after you close the browser. To stop it:

pkill -TERM -x RedLeaf

The AI engine, the private database and the ~/Leaf folder stop with it.

What's different from Windows

  • Doctor, the recovery companion, is Windows only for now.
  • The off-site backup copy is not available on Linux yet. Local database backups work.
  • Some local model providers for voice and images are built for Windows first and may not be offered on Linux.
