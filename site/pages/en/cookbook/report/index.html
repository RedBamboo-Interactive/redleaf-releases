What you can ask

  • Every Monday at 8, turn the sales export in Reports into a one-page summary. Flag anything that moved more than 10%.
  • Why are cancellations up? Look at the dates.
  • Compare this quarter with the same quarter last year.
  • Move the report to Friday afternoon, and skip August.

How it works

  1. Put the data where Nova can read itWorkspace is a real folder on your disk. Save the export there, by hand or from the tool that makes it.
  2. Ask onceSay what the report should cover and when it should run. Nova creates the schedule and shows it to you.
  3. It runs on its ownAt the set time, Nova reads the latest file and writes the report as a page. Last week's page stays, so the history builds up.
  4. Only the news reaches youWhen a number moves past your threshold, Nova says so in Live, with what she thinks caused it.
