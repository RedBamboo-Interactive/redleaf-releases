Transcript

Opening

A customer finds a bug in your product. Someone has to fix it, without breaking what already works.

So I hand the job to a coding session, and bring it back to you, ready to merge.

The report

It starts in a discussion: a customer's bug report. Code is RedLeaf's app for software projects, and a session there is a coding worker that stays with one project until the job is done. So I write a brief, and hand the fix to a session. The pink circle stays on while it works.

Its own branch

The session gets its own branch, and Code gives that branch its own folder, called a worktree. Your main checkout, the project folder you work in, isn't touched, so you can keep working there.

Watching it work

Open the session, and you can watch it work. It finds the cause, fixes it, with a test, runs every test suite, then opens a pull request: the change, ready for review.

Review and merge

When it's done, the discussion gets a callback, a note that the session finished, and I pick it up. I read the change, and run Auto Review, Code's own AI review. The fix is small, and every test passes. Merging is your call. You approve, I merge, and the customer's reply is ready for you to send.

Under the hood

So what's underneath? A discussion, and a brief. The session doesn't share my memory, so I write down what it needs. It runs in Code, on your project's repository, and you can open it any time to watch, approve a step, or add a message.

Its branch gets a worktree, beside your project. One writer per folder, so your checkout stays yours. The tests run in the worktree, and the work comes back as a pull request.

When the session finishes, the callback brings me back. I review it, with Auto Review as a second opinion, and nothing reaches your main branch until you approve. If it needs another pass, I send the same session my notes, and it picks up where it left off.

Recap

So: I hand the job to a Code session, with a brief. It works on its own branch, and your checkout stays yours. And nothing merges until you approve.
