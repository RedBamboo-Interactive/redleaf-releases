Under the hood

So how does that work? Every app in RedLeaf calls one local API, and I call the same one.

Agents, skills, automations, pages: each is an entity, a record of a known type, and the API describes every field. So the same few calls create any of them.

For everything else, the API publishes a map I can search, and each extension you install adds to it. Every call I make is signed, and shows up as a square you can open.

And some things stay yours: access levels, what gets installed, and every approval.
