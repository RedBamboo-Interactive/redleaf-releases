The operating system for your AI agents.

One app for Windows and Linux where your agents get the tools, the apps and a memory that lasts. Make a game, learn a language, plan a trip, run your home, and see every step they take.

Agents

Meet Nova, your first agent.

Nova comes with RedLeaf. She's the one you talk to: tell her what you're after and she plans it with you, hands the work to the right app, remembers what you did together and tells you when something needs you.

  • {{icon:chat-circle}}
    Type or talkIn the chat or by voice, whichever is closer.
  • {{icon:book-open}}
    She remembersHer memory is pages you can open and edit.
  • {{icon:lightning}}
    Across the appsCode, Workspace, images, voices and schedules.

Then make your own. An agent can be whatever you need, with its own name, personality, voice and workspace. A few ideas of what yours could be:

  • LeniA German tutor
  • ZibA stargazing guide for the kids
  • MochiA bedtime storyteller
  • BoltA tester for your builds
  • AnaA running coach
  • SageA research librarian
  • MarcoA weekly meal planner

Examples only. You choose who your agents are and what they do.

Your project

Nova keeps the whole project in her head.

You decide what the project should become. Nova turns that into jobs, hands each one to a coding session, checks the result, and keeps the roadmap, the decisions and the history in her memory.

{{icon:game-controller}}

A video game

Mechanics, levels, menus, and the bug that only happens on the second jump. Nova keeps the design notes and the to-do list, and can make the art and the voices too.

{{icon:device-mobile}}

An app

From the first screen to a build you can hand to friends. Features move forward side by side, with the tests run on every change.

{{icon:globe-simple}}

A website

A portfolio, a shop, a page for your band. Describe it, see it running on your own computer, and change it in plain words.

What you install

Four core apps. Then whatever you need.

RedLeaf is one local service. Four core apps come with every install and share the same agents, files and history, so work moves between them without copy and paste. Everything else is an extension: add what you need from the Marketplace, and remove it just as easily.

Your main agent and the one you talk to. Keeps parallel discussions, a Live timeline, and a heartbeat that checks on things for you.

How it is built

It runs on your machine, and you can see what it does.

{{icon:eye}}

Every step on the record

Each thing an agent does is a square you can open: the file it read, the change it made, the command it ran and what came back. Code sessions keep their full transcripts, and every memory is a page you can read and correct.

{{icon:lock-simple}}

Private by default

Your conversations, files and your agents' memory stay on your computer, and RedBamboo never receives them. No analytics. Anonymous usage statistics, counts like “3 sessions today” and never what was in them, stay off unless you turn them on.

{{icon:house}}

On your own computer

RedLeaf, its database and every workspace live on your machine, and images, voices and music can render on your own graphics card.

{{icon:lightning}}

Your choice of AI

Connect the AI accounts you already use, or run local models. Prompts go only to the provider you choose, under that provider's terms.

Download

Install RedLeaf.

Setup installs the suite, prepares the agent workspace and walks you through your account and your first AI provider. It takes a few minutes.

  1. 01

    Run the installer

    On Windows, RedLeaf Setup. On Linux, the one-line install in a terminal, as yourself.

  2. 02

    Approve the agent filesystem

    Windows asks once for administrator approval to install WinFsp. Linux uses FUSE 3, which you install beforehand.

  3. 03

    Create the local owner

    Your RedLeaf account and the agent workspace stay on this machine.

  4. 04

    Connect an AI provider

    Pick a provider, finish its sign-in, and open your first discussion with Nova.

Before you install. RedLeaf needs FUSE 3 for your ~/Leaf folder: sudo dnf install fuse3 on Fedora, sudo apt install fuse3 on Debian and Ubuntu. It runs with SELinux enforcing; there is nothing to relabel or turn off. It installs into your home folder and checks the launcher against the signed release record before running it.

Requirements and dependencies

Windows x64 or Linux x64

Linux is tested on Fedora with SELinux enforcing.

FUSE 3 on Linux

Provides your ~/Leaf folder. Install the fuse3 package first.

Administrator approval on Windows

Needed once for WinFsp, which provides agent workspace drives.

An AI provider account

Use the sign-in flow of the supported provider you choose.

Git

Needed when Code works with local repositories: Git for Windows, or your distribution's git package. RedLeaf does not install Git.

Internet access

To download components and reach your AI provider.
