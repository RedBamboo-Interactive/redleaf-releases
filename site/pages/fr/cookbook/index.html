Qu'allez-vous en faire ?

Six usages de RedLeaf, de la livraison de code à l'apprentissage d'une langue. Chaque page montre quoi demander, ce qui se passe dans RedLeaf et ce dont vous avez besoin, avec une démonstration animée des écrans que vous verrez. Nova est l'agent fourni avec RedLeaf ; vous pouvez ajouter les vôtres.

Avant de commencer

Tous les cas d'usage commencent de la même façon : installez RedLeaf, créez votre compte propriétaire local et connectez un fournisseur d'IA. La configuration vous guide pour les trois. Ensuite, ouvrez Nova et dites ce que vous voulez avec vos mots ; elle sait quelle appli utiliser.

Bloqué, ou vous avez repéré un cas d'usage à ajouter ? Dites-le-nous sur le Discord de Leaf.
