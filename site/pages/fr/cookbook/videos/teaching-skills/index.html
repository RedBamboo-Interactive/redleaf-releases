Transcription

Ouverture

Chaque équipe a sa façon de faire. Vous ne devriez pas avoir à l’expliquer chaque semaine.

Montrez-moi une fois, et je continuerai à faire à votre façon.

La réunion du lundi

Après la réunion hebdomadaire, vous me donnez les notes brutes. Je les mets au propre à ma façon. Ça se lit bien, mais votre équipe le veut autrement. Alors je réécris.

En faire un skill

Puis vous me demandez d’en faire un skill. Un skill est une procédure, écrite une fois, qu’un agent reprend chaque fois qu’elle s’applique. Je le crée, et je le donne aussi à l’autre agent de l’équipe, pour que nous travaillions tous les deux de la même façon.

Le skill

C’est une page dans RedLeaf, comme un agent. La description dit quand l’utiliser. Les instructions disent comment. Et le champ Agents montre qui l’a.

Une semaine plus tard

Une semaine plus tard, nouvelle réunion, nouvelles notes. Rien d’autre. Je vois que le skill s’applique, alors je l’ouvre, et le compte rendu sort à votre façon, sans qu’on me le demande.

Une règle pour tous

Certaines règles sont plus petites qu’une procédure. Ce sont les protocoles. Un protocole est une règle de conduite courte, qui fait partie des instructions de chaque agent qui l’a. Par exemple, la façon d’écrire une date, pour que personne ne se demande de quel vendredi il s’agit.

Sous le capot

Alors, qu’y a-t-il en dessous ? Un skill est une seule page : une description écrite comme un déclencheur, des instructions en langage simple, et les fichiers dont il a besoin, comme un modèle de document.

Vous le donnez aux agents dans leur champ Skills. RedLeaf place une copie en lecture seule dans l’espace de travail de chaque agent, au format qu’attend son fournisseur d’IA, et la tient à jour quand vous modifiez le skill.

Je lis d’abord les descriptions. Quand l’une d’elles correspond au travail, j’ouvre le skill en entier.

Les faits qui changent vont dans ma mémoire. Les procédures vont dans les skills. Les protocoles sont les règles courtes que partagent vos agents. Et les skills de heartbeat suivent la même idée, pour ce que mon heartbeat peut faire à chaque battement.

Récapitulatif

Donc : montrez-moi une fois, puis faites-en un skill. Un même skill fonctionne pour chaque agent à qui vous le donnez. Les faits vont dans la mémoire, les procédures dans les skills, et les règles partagées dans les protocoles.

La prochaine fois : ce que je peux atteindre. À bientôt.
