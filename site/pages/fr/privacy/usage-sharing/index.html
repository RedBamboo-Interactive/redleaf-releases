Ce qui est collecté, et seulement si vous l'acceptez

« Usage sharing » est le paramètre de RedLeaf pour les statistiques d'utilisation anonymes : des décomptes quotidiens de la façon dont RedLeaf est utilisé, pour que les personnes qui le développent puissent voir ce qui fonctionne. Il n'inclut jamais vos conversations, prompts, fichiers, contenus générés ni rien de ce que vos fournisseurs d'IA renvoient. Il est désactivé par défaut. Si vous l'activez, votre installation envoie un petit rapport par jour pour chaque question listée dans Settings > Usage sharing. Un rapport contient un identifiant aléatoire, la question et sa version, le jour, et des décomptes regroupés par catégories fixes (par exemple « Codex : 3 sessions »). Si vous choisissez de partager avec un nom, le nom que vous avez saisi est stocké avec votre identifiant. Les rapports ne contiennent jamais vos messages, prompts, contenus générés, noms de fichiers ou de projets, titres, informations de compte ni heures exactes. Le serveur de statistiques n'utilise votre adresse IP que pour limiter la fréquence à laquelle des rapports peuvent être envoyés. Il ne la stocke pas et ne l'inscrit pas dans ses journaux. Cloudflare, qui exploite ce serveur, voit nécessairement cette adresse lorsque votre installation se connecte.

Comptes actifs par jour (RedLeaf auto-hébergé) dispose de son propre interrupteur dans Settings > Usage sharing. Il est désactivé par défaut pour chaque compte, y compris pour les personnes qui partagent déjà d'autres statistiques d'utilisation. Après votre accord, RedLeaf comptabilise votre compte connecté une fois par jour UTC lorsque vous interagissez avec l'application. Une fois la journée terminée, votre installation envoie uniquement le jour UTC, le nombre de comptes actifs ayant donné leur accord et un code aléatoire qui permet de renouveler l'envoi pour ce jour. Le rapport ne contient ni identifiant de compte ou d'installation, ni nom, ni détail d'activité, ni contenu. Seuls les comptes auto-hébergés qui participent sont comptés. Une personne qui possède des comptes sur plusieurs installations peut être comptée plusieurs fois.

Pourquoi

Pour comprendre comment les testeurs utilisent Leaf, afin de pouvoir l'améliorer. Chaque question indique pourquoi elle est posée.

Base légale

Votre consentement (article 6.1.a du RGPD ; LPD suisse). Vous pouvez le retirer à tout moment dans Settings > Usage sharing, et le retirer est aussi simple que de le donner.

Lieu de stockage

Sur l'infrastructure de Cloudflare, dans une base de données restreinte à l'Union européenne. Cloudflare les traite pour le compte de Laurent. Personne d'autre ne les reçoit.

Durée de conservation

Tant qu'une question est active et que vous partagez vos statistiques. Lorsqu'une question est retirée, les réponses rattachées à des personnes sont supprimées au bout de 30 jours ; seuls des totaux portant sur au moins cinq testeurs peuvent être conservés, sans identifiant. Les identifiants pour lesquels aucun rapport n'a été reçu depuis 180 jours sont supprimés.

Pour les comptes actifs par jour, l'installation conserve les relevés quotidiens par compte tant qu'un envoi est en attente, pendant au plus sept jours UTC terminés. Le serveur conserve une empreinte du code de renouvellement jusqu'à la fin de cette période de sept jours et les totaux quotidiens pendant 400 jours. Les données expirées sont supprimées lors d'un nettoyage périodique.

Vos droits

Vous pouvez consulter dans Settings > Usage sharing les rapports rattachés à votre identifiant, les exporter avec les données de votre compte ou les supprimer avec Delete my data (supprimer mes données). Désactivez l'interrupteur distinct des comptes actifs par jour pour cesser d'être compté et retirer votre contribution en attente d'envoi. Le serveur ne peut pas retirer la contribution d'un compte d'un total quotidien qu'il a déjà reçu. Vous pouvez contacter Laurent pour toute question et introduire une réclamation auprès de votre autorité de protection des données (en France, la CNIL, dont nous relevons ; ailleurs dans l'UE, votre autorité nationale ; en Suisse, le PFPDT).
