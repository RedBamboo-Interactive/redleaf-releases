Politique de confidentialité

Dernière mise à jour : 13 novembre 2026

En bref. RedLeaf fonctionne sur votre ordinateur et y conserve vos conversations, vos fichiers et la mémoire de vos agents. RedBamboo Interactive ne les reçoit pas. Ce site ne dépose aucun cookie et n'utilise aucun outil de mesure d'audience. Les données ne quittent votre machine que pour atteindre les services que vous choisissez d'utiliser : les fournisseurs d'IA que vous connectez, GitHub pour les téléchargements et les mises à jour, et notre serveur de statistiques si vous activez les statistiques d'utilisation anonymes.

Responsable du traitement

Laurent Bécherel (RedBamboo Interactive), Zurich, Suisse, est responsable du traitement décrit ici. Contact : becherel.laurent@gmail.com.

Ce site

Ce site est hébergé sur GitHub Pages par GitHub, Inc. Lorsque vous ouvrez une page, GitHub reçoit votre adresse IP et les informations habituelles de la requête (navigateur, page, heure) afin de vous la fournir, et peut les conserver dans ses journaux de serveur à des fins de sécurité. Consultez la Déclaration de confidentialité générale de GitHub.

Pour afficher la version actuelle, la section de téléchargement lit le flux de versions signé sur raw.githubusercontent.com, également exploité par GitHub. Rien d'autre n'est chargé depuis des tiers : ni cookies, ni mesure d'audience, ni publicité, ni polices ou vidéos intégrées. Les démos de ce site sont des animations qui s'exécutent dans votre navigateur et n'envoient rien. Si vous choisissez une langue, votre navigateur conserve ce choix dans le stockage local de ce site, pour que le site cesse de vous suggérer une autre langue ; ce choix n'est jamais transmis, ni à nous ni à qui que ce soit.

Les liens vers Discord ou GitHub vous mènent vers ces services, dont les propres politiques s'appliquent une fois que vous y êtes.

Le logiciel RedLeaf

Ce qui reste sur votre machine

Votre compte RedLeaf, vos conversations, les espaces de travail et la mémoire de vos agents, vos sessions Code, les images et fichiers audio générés, vos paramètres et vos sauvegardes sont stockés localement, dans la base de données et les dossiers de RedLeaf sur votre ordinateur. RedBamboo Interactive n'y a pas accès.

Les sessions Code exécutent des outils comme Git sur votre machine. Lorsqu'un agent pousse vers un dépôt distant ou appelle un service extérieur sur votre instruction, ces données vont au service que vous lui avez indiqué.

Fournisseurs d'IA

Lorsque vous utilisez un modèle hébergé, RedLeaf envoie votre requête directement depuis votre ordinateur à ce fournisseur. RedBamboo Interactive n'est pas partie à cet échange et ne le voit pas. Chaque fournisseur décide combien de temps il conserve les requêtes et s'il les utilise pour améliorer ses modèles. Lisez leurs conditions avant de les connecter, et privilégiez des fournisseurs locaux pour les contenus qui ne doivent pas quitter votre machine.

Base légale

La mise à disposition de ce site repose sur notre intérêt légitime à le publier et à le sécuriser (article 6.1.f du RGPD). Les statistiques d'utilisation anonymes reposent sur votre consentement (article 6.1.a du RGPD), que vous pouvez retirer à tout moment dans Settings. Les mêmes principes s'appliquent au titre de la loi fédérale suisse sur la protection des données (LPD).

Vos droits

Vous pouvez demander l'accès aux données personnelles que nous détenons à votre sujet, leur rectification ou leur effacement, vous opposer à leur traitement et demander à en recevoir une copie dans un format portable. Les données que RedLeaf stocke sur votre propre ordinateur restent sous votre contrôle : vous pouvez les exporter ou les supprimer vous-même à tout moment. Pour exercer un droit, écrivez à l'adresse ci-dessus. Vous pouvez aussi introduire une réclamation auprès d'une autorité de protection des données : en Suisse, le PFPDT ; dans l'UE, l'autorité de votre pays.

Enfants

RedLeaf n'est pas destiné aux enfants de moins de 16 ans, et nous ne collectons pas sciemment leurs données.

Modifications

Lorsque cette politique change, la date indiquée en haut de page change avec elle. Les modifications importantes de ce que le logiciel envoie sont annoncées dans les notes de version avant leur publication.
