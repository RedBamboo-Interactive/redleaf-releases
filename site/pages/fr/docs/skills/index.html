Skills et protocoles.

Une skill est un paquet de savoir-faire qu'un agent peut mobiliser quand c'est pertinent : comment relire une pull request, comment fonctionne votre processus de publication, comment parler à votre maison connectée. Écrivez-la une fois et donnez-la à n'importe quel agent. Les protocoles en sont la version courte : une règle de conduite partagée entre agents.

Ce qu'est une skill

ChampÀ quoi il sert
DescriptionQuand la skill s'applique. L'agent la lit pour décider s'il ouvre la skill : soyez donc précis. Jusqu'à 1 024 caractères.
InstructionsLa skill elle-même, en Markdown : étapes, règles, exemples, pièges.
Package filesDes fichiers supplémentaires facultatifs : scripts, modèles, tableaux de référence.
Icon, TagsPour la retrouver dans la bibliothèque et dans le sélecteur de l'agent.
TrustVotre vérification du contenu exécutable ou importé.
AgentsLes agents qui l'utilisent.

Les skills sont des entités de type Agent Skill, dans Database › Entities. Ouvrez-en une pour modifier ses instructions, ou ses Package files (fichiers du paquet) pour envoyer des fichiers, puis Save package.

Donner une skill à un agent

Sur la page de l'agent, ajoutez-la au champ Skills. RedLeaf place une copie en lecture seule dans l'espace de travail de l'agent, au format qu'attend son fournisseur d'IA, et la tient à jour quand vous modifiez la skill. Ne modifiez pas ces copies : modifiez la skill, et elles suivent.

Les extensions peuvent apporter leurs propres skills. Quand vous en installez une qui en apporte, RedLeaf vous demande à quels agents Give this skill to (donner cette skill), avec Nova présélectionnée.

Écrire une bonne skill

  • Rédigez la description comme un déclencheur : « À utiliser pour relire une pull request dans ce dépôt », et non « trucs de PR ».
  • Une seule tâche par skill. Deux skills ciblées valent mieux qu'une seule qui couvre tout.
  • Dites quoi vérifier, pas seulement quoi faire. Les agents suivent bien des critères d'acceptation.
  • Mettez les faits qui changent dans la mémoire, et les procédures dans les skills.

Les skills de Nova

Nova démarre avec des skills pour travailler dans RedLeaf, pour l'ingénierie, pour déléguer à Code, pour intégrer des éléments RedLeaf dans une réponse, ainsi que les trois skills de rêve qui consolident sa mémoire pendant la nuit. Retirez-en n'importe laquelle de son champ Skills si vous ne voulez pas ce comportement.

Protocoles

Un protocole (une entité Agent Protocol) est une courte règle de conduite, jusqu'à 1 500 caractères, ajoutée aux instructions d'un agent après son Output Protocol. Utilisez-en un pour une règle que plusieurs agents doivent partager. Le protocole par défaut de Nova porte sur les réactions emoji : elle réagit de temps en temps, comme le ferait une personne dans un chat, et n'utilise jamais une réaction à la place d'une réponse à quelque chose de personnel. Ajoutez des protocoles à un agent dans son champ Protocols.

Skills du heartbeat

Un agent avec Live activé a un champ Heartbeat Skills distinct : ce que les ticks de son heartbeat peuvent faire. Chaque tick les transporte en entier : chacune doit donc rester sous 1 500 caractères et renvoyer vers une skill complète pour tout ce qui est plus long. Celles qui sont trop longues ou vides sont refusées, avec une raison. Voir Planifications et heartbeat.
