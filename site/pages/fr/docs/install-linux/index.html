Premiers pas

Installer sur Linux.

RedLeaf s'installe dans votre dossier personnel, sous votre compte, sans accès root. Un court script vérifie le lanceur par rapport à l'enregistrement de version signé, et le lanceur vérifie tout le reste avant d'installer.

Avant de commencer

  • Linux x64. RedLeaf est testé sur Fedora avec SELinux en mode enforcing. Il n'y a rien à réétiqueter ni à désactiver.
  • FUSE 3, qui fournit votre dossier ~/Leaf. Installez-le d'abord : 
    # Fedora
sudo dnf install fuse3
# Debian and Ubuntu
sudo apt install fuse3
# Arch
sudo pacman -S fuse3
  • Les outils habituels : curl, tar, sha256sum, python3 et mktemp. La plupart des distributions les ont déjà.
  • Un fournisseur d'IA auquel vous pouvez vous connecter. Voir Fournisseurs d'IA.
  • Git, depuis votre distribution, seulement si vous voulez utiliser Code sur vos propres projets.

Installer

  1. Copiez la commandeAllez à la section de téléchargement, choisissez l'onglet Linux et copiez la commande d'installation. Elle ressemble à curl -fsSL https://…/install.sh | sh et pointe toujours vers la version signée actuelle.
  2. Exécutez-la sous votre propre compteCollez-la dans un terminal. N'utilisez pas sudo : RedLeaf s'installe par utilisateur et refuse de tourner en root.
  3. Laissez-le vérifier et installerLe script lit le flux signé, télécharge le lanceur et compare sa taille exacte et son SHA-256 à l'enregistrement signé. Rien ne s'exécute s'ils ne correspondent pas. Le lanceur vérifie ensuite le flux à son tour et installe la suite.
  4. Ouvrez RedLeafVotre navigateur ouvre http://127.0.0.1:18804. Sur une machine sans écran, par exemple en SSH, le lanceur affiche l'adresse à la place. Continuez avec Configurer RedLeaf.

Vous préférez ne pas envoyer un script directement dans un shell ? Choisissez plutôt Download Nightly dans l'onglet Linux, vérifiez l'archive avec Show SHA-256, puis :

tar -xzf redleaf-linux-x64.tar.gz redleaf-launcher
./redleaf-launcher open
{{icon:warning}}

La version Linux n'est peut-être pas encore sortie. Si l'onglet Linux indique que la version Linux n'est pas publiée, il n'y a rien à installer pour l'instant. Les versions Windows sont publiées séparément.

Où se trouve quoi

QuoiOù
Le programme~/.local/share/RedLeaf-Suite
Vos données~/.local/share/RedLeaf : les réglages, la base de données privée et les journaux. Sauvegardez ce dossier pour tout conserver.
Espaces de travail des agents et vos projets~/Leaf/Workspaces et ~/Leaf/Projects, tant que RedLeaf tourne
Entrée de menuRedLeaf dans le menu des applications

Si XDG_DATA_HOME est défini, RedLeaf l'utilise à la place de ~/.local/share.

Démarrer et arrêter

Lancez RedLeaf depuis le menu des applications. Il n'y a pas d'icône dans la zone de notification sous Linux, et RedLeaf continue de tourner une fois le navigateur fermé. Pour l'arrêter :

pkill -TERM -x RedLeaf

Le moteur d'IA, la base de données privée et le dossier ~/Leaf s'arrêtent avec lui.

Différences avec Windows

  • Doctor, l'assistant de récupération, n'existe pour l'instant que sous Windows.
  • La copie de sauvegarde hors site n'est pas encore disponible sous Linux. Les sauvegardes locales de la base de données fonctionnent.
  • Certains fournisseurs de modèles locaux pour la voix et les images sont d'abord conçus pour Windows et peuvent ne pas être proposés sous Linux.
