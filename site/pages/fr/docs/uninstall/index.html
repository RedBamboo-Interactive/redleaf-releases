Aide

Désinstaller et vos données.

La désinstallation supprime le programme et conserve vos données : vous pouvez revenir plus tard et tout retrouver là où vous l'aviez laissé. Supprimer aussi les données est une étape distincte, et délibérée.

Désinstaller

RedLeaf se désinstalle avec son lanceur, le fichier même qui a servi à l'installer. Utilisez une copie téléchargée du lanceur, pas celle qui se trouve dans l'installation.

Windows

Ouvrez PowerShell dans le dossier où vous avez téléchargé le lanceur, par exemple Téléchargements, et lancez-le avec uninstall :

.\redleaf-launcher-<version>-<build>-win-x64.exe uninstall

Utilisez le nom complet du fichier que vous avez téléchargé ; il commence par redleaf-launcher.

Si vous ne l'avez plus, téléchargez-le à nouveau depuis la section de téléchargement.

Linux

Téléchargez l'archive Linux depuis la section de téléchargement, extrayez-en le lanceur, puis exécutez :

tar -xzf redleaf-linux-x64.tar.gz redleaf-launcher
./redleaf-launcher uninstall

Le lanceur arrête RedLeaf, puis supprime le programme installé, son état de mise à jour et l'entrée du menu Démarrer ou du menu des applications. Sous Linux, il démonte aussi ~/Leaf.

Ce qui reste

Vos données sont conservées : les paramètres, la base de données privée avec vos discussions, vos agents et leur mémoire, les clés de chiffrement, les ressources et les sauvegardes. Réinstallez plus tard, et RedLeaf les retrouve.

QuoiWindowsLinux
Paramètres, base de données, journaux, sauvegardes%LOCALAPPDATA%\RedLeaf~/.local/share/RedLeaf
Clés de chiffrement%LOCALAPPDATA%\RedSuitedans ~/.local/share
Le programme (supprimé)%LOCALAPPDATA%\RedLeaf-Suite~/.local/share/RedLeaf-Suite

Les espaces de travail des agents sur L: ou dans ~/Leaf ne sont pas des fichiers à part : ce sont une vue des pages de la base de données, et ils disparaissent quand RedLeaf n'est pas en marche.

Supprimer vos données

{{icon:warning}}

Cette action est irréversible. Supprimer ces dossiers efface chaque discussion, agent, mémoire et sauvegarde qu'ils contiennent. Si une partie de ces données peut encore vous servir, gardez-en d'abord une copie, ou conservez votre copie hors site et sa phrase de récupération.

Après la désinstallation, supprimez %LOCALAPPDATA%\RedLeaf et %LOCALAPPDATA%\RedSuite sous Windows, ou ~/.local/share/RedLeaf sous Linux. WinFsp, installé pendant la configuration, est un programme distinct : désinstallez-le depuis Settings › Apps (Paramètres › Applications) dans Windows si rien d'autre ne l'utilise.

Les données conservées par vos fournisseurs d'IA, comme l'historique des conversations dans votre compte chez le fournisseur, relèvent de ces fournisseurs. RedLeaf ne peut pas les supprimer à votre place.

Si vous avez activé les statistiques d'utilisation anonymes, Delete my data dans Settings › Usage sharing supprime ce qui a été envoyé, comme le décrit la notice des statistiques d'utilisation. Faites-le avant de désinstaller.
