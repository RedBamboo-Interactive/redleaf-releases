Pour aller plus loin

Accès à distance.

Par défaut, RedLeaf n'est joignable que depuis l'ordinateur sur lequel il tourne. Si vous voulez vos agents sur votre téléphone, vous pouvez le publier via un Cloudflare Tunnel, sans port ouvert et avec HTTPS automatique, et exiger une connexion Google devant.

Les options

Ouvrez Settings › Network & Access. L'onglet Remote Access propose :

OptionCe que cela signifie
Local onlyLe réglage par défaut. RedLeaf n'est joignable que depuis cette machine, sans exposition et sans autres comptes.
Remote via Cloudflare TunnelRedLeaf obtient une adresse publique sur votre propre domaine, via Cloudflare. Nécessite un compte Cloudflare gratuit et un nom de domaine.

L'onglet Authentication ajoute Google OAuth sign-in (connexion Google OAuth), pour l'accès à distance ou pour plusieurs personnes.

Configurer un tunnel

  1. Créez le tunnel dans CloudflareDans votre tableau de bord Cloudflare, créez un tunnel pour votre domaine et copiez son jeton.
  2. Activez d'abord la connexion GoogleDans Authentication, créez un client OAuth dans Google Cloud, puis collez son Client ID et son Client Secret. Changer de mode de connexion redémarre RedLeaf.
  3. Connectez le tunnelDe retour dans Remote Access, choisissez l'option tunnel, collez le Tunnel Token et le Public Hostname, puis enregistrez. Les changements du tunnel s'appliquent immédiatement.
  4. Ouvrez-le sur votre téléphoneRendez-vous sur votre nom d'hôte et connectez-vous. Nova peut être ajoutée à votre écran d'accueil comme une appli.
{{icon:warning}}

Une adresse publique est une porte. Quiconque peut joindre votre nom d'hôte atteint la page d'accueil de vos agents. Exigez la connexion Google avant de publier, et gardez les agents qui lisent du contenu non fiable sur un niveau d'accès modeste.

Ce qui fonctionne loin de votre bureau

  • Discussions, Code, Workspace et les autres applis fonctionnent dans le navigateur d'un téléphone, avec une mise en page pensée pour les petits écrans.
  • Le mode vocal fonctionne sur téléphone. Voir Voix et Float Nova.
  • Attach what I see peut partager la page affichée, mais pas les écrans de votre ordinateur.
  • Float Nova est réservé aux ordinateurs.

Votre ordinateur fait toujours tout le travail : il doit donc être allumé, avec RedLeaf en marche.

Plusieurs personnes

La connexion Google permet aussi à plusieurs personnes d'accéder au même RedLeaf, et RedLeaf prévoit trois rôles pour elles : Admin, Editor et Viewer. Voir Base de données et vues. La gestion des personnes reste sommaire dans la préversion : il n'y a pas encore d'écran d'invitation ni de liste des utilisateurs.
