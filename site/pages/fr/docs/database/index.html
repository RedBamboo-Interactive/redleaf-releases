Base de données et vues.

Sous les applis, tout dans RedLeaf est une entité : les pages, les agents, les skills, les dépôts, les automatisations, et tout ce que vous définissez vous-même. L'appli Database affiche l'ensemble, vous permet de créer vos propres types, et cherche dans tout à la fois.

Entités et types

Chaque entité a un type, et chaque type a des champs. Un type Character pour votre jeu pourrait avoir un nom, un portrait, une faction et une liste de quêtes. Les agents peuvent les lire et les remplir comme vous : c'est ainsi que la structure d'un projet reste partagée entre vous et eux.

  1. Ouvrez DatabaseDepuis le sélecteur d'applis, puis Entities. La liste affiche chaque Entity Type (type d'entité), rangé dans des dossiers. Les types propres à RedLeaf se trouvent dans la section verrouillée System, et le filtre Scope restreint la liste à une appli ou à un espace de travail.
  2. Créez un typeChoisissez New type et donnez-lui un nom, par exemple Document, Character ou Item.
  3. Ajoutez des champsDans les champs du type, ajoutez ce dont il a besoin et choisissez Save Changes.
  4. Ajoutez des entitésSous Instances, choisissez New. Ou demandez à un agent de les remplir à partir de vos notes.

Types de champs : String, Number, Float, Boolean, Date, Select, Multi Select, Entity Ref, Entity List, Media, Color, JSON et Markdown. Entity Ref et Entity List relient des entités entre elles, par exemple une quête à ses personnages.

Recherche

Database › Search est une recherche unique dans tout ce que vous avez le droit de lire. Cherchez dans Entities (noms, propriétés et références) ou dans Records (pages, discussions, sessions et autres flux indexés). Affinez par type d'entité, par champ à faire correspondre, ou par date. Les résultats respectent les permissions : chaque personne ne trouve que ce qu'elle peut voir.

Des vues dans vos projets

Dans un projet Workspace, New view affiche un ensemble d'entités dans la disposition de votre choix. Donnez-lui un nom, choisissez le type d'entité et un mode d'affichage, puis Create View.

ModeCe que vous obtenez
BoardDes colonnes regroupées selon un champ de sélection, comme un statut. Faites glisser une carte vers une autre colonne pour changer la valeur du champ.
ListUne liste verticale, éventuellement regroupée selon un champ.

Un tableau regroupé par statut, c'est une feuille de route : l'agent peut déplacer les cartes à mesure que le travail avance, et vous voyez le même tableau.

Pages

Un projet Workspace est une page, et les pages s'imbriquent. Ouvrez-en une pour y écrire, épinglez les éléments que vous utilisez le plus sous Structure, et choisissez Share pour créer un lien vers elle. Chaque modification est versionnée, avec Undo this change (annuler cette modification) dans son historique.

Rôles

RedLeaf a trois rôles : Admin, avec un accès complet, paramètres compris ; Editor, qui peut lire et écrire tout le contenu mais ne peut pas gérer les utilisateurs ni les rôles ; et Viewer, en lecture seule. Le compte propriétaire créé pendant la configuration est un admin. Pour d'autres personnes, il faut la connexion Google : voir Accès à distance.
