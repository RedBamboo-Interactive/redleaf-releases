Aide

Dépannage et Doctor.

La plupart des problèmes se manifestent à l'un de ces trois endroits : l'écran de récupération quand RedLeaf ne peut pas démarrer, Setup & Health quand quelque chose dont il dépend ne va pas, ou un fournisseur qui ne répond plus. Voici ce que chacun signifie et ce qu'il faut faire.

Vérifiez d'abord l'état de santé

Ouvrez Settings › Setup & Health. Cette page lance des vérifications en direct sur les services de base de RedLeaf, ses capacités et ses accès, et affiche All systems healthy (tout fonctionne) ou System needs attention (le système demande votre attention), avec les vérifications en échec et leur raison. Choisissez Run health checks again après avoir corrigé quelque chose.

RedLeaf ne démarre pas

Si RedLeaf n'arrive pas à terminer son démarrage sur une installation existante, il affiche Recover RedLeaf au lieu de la configuration. Il explique simplement ce qui a échoué, et ce qu'il est advenu de vos données. Par exemple, qu'il n'a pas pu joindre la base de données et qu'il n'y a donc rien lu ni rien modifié.

  • Try again relance tout le démarrage. Une mise à jour de la base de données peut prendre plusieurs minutes.
  • Open log folder ouvre les journaux, un fichier par jour.

Ne réinstallez pas RedLeaf et ne supprimez pas son dossier de données pour passer cet écran. Votre installation est toujours là, et la configuration n'a pas besoin d'être refaite. Si Try again ne suffit pas, demandez dans #bug-reports sur le Discord de Leaf, avec le fichier journal le plus récent et une capture d'écran de la page.

« RedLeaf is already running. »Il se trouve dans la zone de notification. Utilisez Open RedLeaf sur l'icône de la barre d'état.
« Server failed to start »Un autre programme utilise le port de RedLeaf, 18804. Fermez-le et relancez RedLeaf.
« Drive L: is already in use »Un autre lecteur ou un autre programme a pris la lettre de l'espace de travail. Libérez-la, ou choisissez un autre Workspace drive dans Settings › Storage › Workspaces.
Le lanceur vous demande de désactiver « Run this program as an administrator » (« Exécuter ce programme en tant qu'administrateur » dans Windows en français)Décochez cette option dans Properties › Compatibility (Propriétés › Compatibilité) du fichier, puis relancez-le en tant que vous-même.
« must not run as root » sous LinuxRelancez l'installeur ou le lanceur sans sudo.
« The FUSE runtime is missing »Installez fuse3 depuis votre distribution, puis Try again.
Claude Code : « Installed, not signed in. »Reconnectez-vous depuis les paramètres du fournisseur dans Settings › Extensions. Si RedLeaf ne trouve pas du tout Claude Code, installez-le, ou indiquez son emplacement dans les paramètres avancés de l'extension.
Codex ne s'installe pas sous LinuxExécutez curl -fsSL https://releases.openai.com/codex/install.sh | sh, puis choisissez Check again.
« Session paused », limite d'utilisation atteinteC'est la limite de votre fournisseur. Envoyez un message après sa réinitialisation, et la session reprend.
Une capacité affiche une lune violette dans ComputeElle est en veille : ses requêtes sont donc gelées. Appuyez sur le bouton en forme de lune pour la réveiller.
Une mise à jour a échouéElle a été annulée. La raison se trouve dans le journal du lanceur, update/logs/launcher.log dans le dossier de données de RedLeaf.

Doctor

Doctor est une trousse de réparation qui continue de fonctionner quand RedLeaf lui-même ne fonctionne plus. C'est une page distincte dans votre navigateur, avec des vérifications de santé, Restart suite, et des sessions de réparation où Claude Code ou Codex peuvent diagnostiquer et réparer l'installation avec vous. Il est installé avec RedLeaf et démarre avec lui. Doctor n'est disponible que sous Windows pour l'instant.

Configurez-le dès maintenant, tant que tout fonctionne :

  1. Créez son jeton d'accèsDans les paramètres de Doctor, sous Access, choisissez Rotate (renouveler) et conservez le jeton dans votre gestionnaire de mots de passe. Il n'est affiché qu'une fois.
  2. Ajoutez-le à vos favorisOuvrez http://127.0.0.1:18899 et ajoutez la page à vos favoris.
  3. Choisissez son IASous Repair sessions, choisissez Claude Code ou Codex.
  4. Décidez pour la réparation sans restrictionElle est activée par défaut : la session de réparation peut agir sans demander à chaque étape. Désactivez-la si vous préférez autoriser chaque étape.

Doctor n'est joignable que depuis votre ordinateur. Si sa page ne s'ouvre pas, vérifiez que Doctor est activé et que son port est libre, et utilisez Restart Doctor dans ses paramètres. Si vous avez perdu le jeton, renouvelez-le de nouveau ; il faut pour cela que RedLeaf soit en marche.

Le problème persiste ?

Demandez sur le Discord de Leaf, dans #bug-reports. Indiquez ce que vous faisiez, ce que vous avez vu, et joignez le fichier journal le plus récent. Vérifiez d'abord qu'il ne contient rien de privé.
