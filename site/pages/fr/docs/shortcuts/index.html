Aide

Raccourcis clavier.

Les raccourcis qui font gagner le plus de temps, réunis au même endroit. Les menus affichent le raccourci à côté de chaque élément pour la discussion ou la session ouverte.

Discussions et sessions

TouchesAction
Ctrl+NNouvelle discussion dans Nova, nouvelle session dans Code
Alt+↓ / Alt+↑Discussion ou session suivante / précédente
Ctrl+Shift+FChercher dans toutes les discussions, ou dans toutes les sessions
Alt+IInfo : fournisseur, modèle, coût, niveau d'accès
Alt+AArtefacts partagés dans la conversation
Alt+RRenommer
Alt+TRédiger un titre à partir de la conversation
Alt+SPartager une copie en lecture seule
Alt+WFermer : arrêter et archiver
Alt+VMode vocal
Alt+Shift+LRéinitialiser la chronologie Live
Ctrl+Alt+NOuvrir Float Nova

La zone de saisie

TouchesAction
EnterEnvoyer. Pendant que l'agent travaille : mettre en file d'attente pour après ce tour, ou rejoindre le tour en cours avec les fournisseurs qui le permettent.
Shift+EnterNouvelle ligne
TabMettre en file d'attente au lieu de rejoindre le tour, avec les fournisseurs qui permettent de le rejoindre
Ctrl+EnterInterrompre et envoyer tout de suite
EscInterrompre l'agent
Shift+TabActiver ou désactiver le mode Plan, dans Code
Touche push-to-talkMaintenez-la enfoncée pour parler. Réglez-la dans Settings › Nova › Voice.
