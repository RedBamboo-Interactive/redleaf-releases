Premiers pas

Configurer RedLeaf.

À sa première ouverture, RedLeaf prépare seul son stockage privé, puis vous guide à travers six courts chapitres. La plupart se règlent en un clic. Deux ont besoin de vous : votre compte et votre fournisseur d'IA.

Préparer RedLeaf

Avant les chapitres, RedLeaf prépare deux choses qui restent sur votre machine. Vous suivez leur progression sous Prepare RedLeaf, et le premier chapitre s'ouvre quand les deux sont prêtes.

  • Le système de fichiers des agents. Sous Windows, RedLeaf télécharge et vérifie WinFsp, puis affiche Windows needs your approval (Windows a besoin de votre autorisation) : acceptez la demande d'installation. Sous Linux, il teste un montage FUSE jetable sous votre utilisateur. Si FUSE manque, installez le paquet fuse3 et choisissez Try again.
  • La base de données privée. RedLeaf télécharge et démarre son propre PostgreSQL. Vous n'avez besoin ni de Docker ni d'un serveur existant. Au premier lancement, cela peut prendre quelques minutes.

Si une étape échoue, choisissez Try again (réessayer). Vous pouvez réessayer sans risque.

{{icon:warning}}

Bloqué sur l'erreur Windows 1005 ? Si Verifying the agent filesystem échoue avec GetFinalPathNameByHandleW failed with Windows error 1005, WinFsp a besoin d'un redémarrage de Windows pour fonctionner. Redémarrez Windows et ouvrez RedLeaf depuis le menu Démarrer : la préparation reprend là où elle s'était arrêtée.

Utilisez Back et Next pour passer de l'un à l'autre. Un chapitre se débloque quand le précédent est terminé.

Connecter l'IA

RedLeaf liste les fournisseurs qu'il trouve sur cet ordinateur et en présélectionne un : Claude Code d'abord, puis Codex. Chacun se connecte par sa propre appli ou sa ligne de commande, dans votre navigateur :

FournisseurComment vous connecter
Claude CodeContinue with Claude pour un abonnement Claude, ou Use Anthropic Console pour une facturation à l'API. Claude Code doit déjà être installé.
CodexContinue with ChatGPT, ou Use an API key. Si Codex n'est pas installé, choisissez Install Codex CLI : RedLeaf installe le paquet d'OpenAI pour votre compte, sans droits d'administrateur.
OpenCodeOpen OpenCode sign-in ouvre un terminal où vous choisissez un fournisseur et vous connectez. Vous installez OpenCode vous-même.

Choisissez ensuite Verify. RedLeaf envoie une requête inoffensive pour prouver que Nova peut utiliser le fournisseur. Si vous avez installé ou connecté quelque chose ailleurs entre-temps, choisissez Check again.

Si RedLeaf ne trouve pas le CLI de Claude Code alors que vous l'avez installé, son dossier manque sans doute à votre PATH. L'installateur de Claude Code le place dans %USERPROFILE%\.local\bin. Ajoutez ce dossier à votre PATH utilisateur, choisissez Exit dans le menu de l'icône de RedLeaf, dans la zone de notification, rouvrez RedLeaf depuis le menu Démarrer, puis choisissez Check again.

{{icon:shield-check}}

Votre connexion reste chez le fournisseur. Claude Code et Codex conservent leurs propres identifiants sur votre PC. Une clé d'API que vous collez est transmise à l'outil du fournisseur, et tout ce que RedLeaf stocke lui-même est chiffré.

Faire connaissance avec Nova

Le dernier chapitre ouvre un petit chat avec Nova. Dites bonjour. Si son message d'accueil ne démarre pas, choisissez Try again. Vous verrez aussi un interrupteur pour partager des statistiques d'utilisation anonymes : des comptages, comme le nombre de sessions lancées, jamais leur contenu. Il reste désactivé tant que vous ne l'activez pas, et vous pourrez le changer plus tard dans Settings › Usage sharing. La notice des statistiques d'utilisation détaille exactement ce qui est envoyé.

Complete setup devient disponible une fois l'espace de travail monté et la réponse de Nova reçue. RedLeaf ouvre alors Nova, avec votre première discussion qui vous attend.

Modifier vos réponses plus tard

Tout ce qui est ici peut être modifié dans Settings. Pour refaire la configuration, ouvrez Settings › Setup & Health et choisissez Revisit setup.
