Premiers pas

Installer sur Windows.

RedLeaf s'installe pour votre compte Windows, sans assistant d'installation ni service. Le lanceur vérifie chaque téléchargement par rapport au flux de versions signé, installe la suite et l'ouvre dans votre navigateur.

Avant de commencer

  • Windows x64. Les appareils ARM ne sont pas encore pris en charge.
  • Un accès à Internet, pour télécharger les composants et joindre votre fournisseur d'IA.
  • Un fournisseur d'IA auquel vous pouvez vous connecter, comme un abonnement Claude pour Claude Code ou un compte ChatGPT pour Codex. Voir Fournisseurs d'IA.
  • Git for Windows, seulement si vous voulez utiliser Code sur vos propres projets. RedLeaf n'installe pas Git.

Vous n'avez pas besoin de carte graphique. Elle ne sert que si vous ajoutez plus tard des modèles locaux pour les images ou la voix.

Installer

  1. Téléchargez le lanceurAllez à la section de téléchargement et choisissez Download Nightly. Le nom du fichier commence par redleaf-launcher. Pour le vérifier, choisissez Show SHA-256 et comparez l'empreinte avec celle que Windows calcule pour le fichier (Get-FileHash dans PowerShell).
  2. Exécutez-le sous votre propre compteDouble-cliquez sur le fichier. Si SmartScreen affiche « Unknown publisher » (« Éditeur inconnu » sur un Windows en français), choisissez More info (Informations complémentaires), puis Run anyway (Exécuter quand même). Ne l'exécutez pas en tant qu'administrateur : RedLeaf s'installe pour votre compte et, si vous le faites, se relance de lui-même sans les droits d'administrateur.
  3. Laissez-le installerLe lanceur lit le flux de versions signé, vérifie la signature et l'empreinte de chaque composant, installe la suite et la démarre. Quand tout est prêt, votre navigateur ouvre RedLeaf à l'adresse http://127.0.0.1:18804.
  4. Autorisez WinFsp une foisLa première étape de la configuration installe WinFsp, qui donne à vos agents le lecteur de leur espace de travail. Windows demande l'autorisation d'un administrateur pour cette seule installation. La suite est décrite dans Configurer RedLeaf.

Ouvrir, fermer et démarrer avec Windows

RedLeaf continue de tourner dans la zone de notification une fois l'onglet du navigateur fermé. Son icône propose Open RedLeaf, un menu Apps avec une entrée par appli, Start with Windows, Restart et Exit. Pour l'ouvrir plus tard, passez par le menu Démarrer ou par l'icône de la zone de notification ; si vous le lancez une deuxième fois, il vous indique simplement qu'il tourne déjà.

Pour l'épingler, ouvrez Démarrer, cherchez RedLeaf, faites un clic droit dessus et choisissez Pin to taskbar (Épingler à la barre des tâches). Pour qu'il démarre à l'ouverture de votre session, activez Start with Windows dans le menu de l'icône ou dans Settings › System.

Gardez le lanceur. Relancer le fichier téléchargé sur une machine où RedLeaf est installé répare l'installation et conserve vos choix. Les mises à jour, elles, s'installent depuis RedLeaf : voir Mises à jour.

En cas de problème

  • Le bouton de téléchargement indique qu'il est indisponible. Le site n'a pas pu joindre le flux de versions signé. Il ne propose jamais de fichier non vérifié à la place : réessayez un peu plus tard.
  • Windows continue de l'exécuter en tant qu'administrateur. Faites un clic droit sur le fichier, ouvrez Properties › Compatibility (Propriétés › Compatibilité), décochez « Run this program as an administrator » (« Exécuter ce programme en tant qu'administrateur »), puis relancez-le.
  • Il a démarré, puis s'est arrêté. Le journal du lanceur se trouve dans %LOCALAPPDATA%\RedLeaf\update\logs\launcher.log. Voir Dépannage et Doctor.
