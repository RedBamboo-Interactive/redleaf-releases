First run

From download to conversation.

RedLeaf guides the setup. No source checkout, Docker, or separate database install.

  1. 01

    Run RedLeaf Setup

    The launcher verifies and installs the signed component graph for your Windows account.

  2. 02

    Create your local account

    RedLeaf provisions its managed database, then asks you to create the first administrator.

  3. 03

    Connect Codex

    RedLeaf installs OpenAI’s signed Codex package for your account, then opens the ChatGPT sign-in flow.

  4. 04

    Meet Nova

    Create your workspace, send the first message, and reopen the same context from the Start menu later.

Before you start

A clean, explicit setup.
