First run

From download to conversation.

RedLeaf guides the setup. No source checkout, Docker, or separate database install.

  1. 1

    Run RedLeaf Setup

    The launcher verifies and installs the signed component graph for your Windows account.

  2. 2

    Create your local account

    RedLeaf provisions its managed database, then asks you to create the first administrator.

  3. 3

    Connect Codex

    RedLeaf runs OpenAI’s verified Codex installer for your account, then opens the ChatGPT sign-in flow.

  4. 4

    Meet Nova

    Send the first message, then reopen the same conversation and context from the Start menu later.

Before you start

Know every prompt.

Nothing important is hidden behind the download button.

  • Windows x64The current release target.
  • Internet accessRequired to download components and authenticate providers.
  • Preview warningSmartScreen may show “Unknown publisher” until Windows publisher signing ships.
  • One admin approvalWinFsp may request permission while Nova’s local workspace support is installed.
  • A Codex credentialUse a ChatGPT sign-in or another authentication method supported by Codex.
