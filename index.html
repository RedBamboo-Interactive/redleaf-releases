First run

Install RedLeaf.

Setup installs the suite, prepares the local agent workspace, and guides you through account and AI provider configuration.

  1. 01

    Run RedLeaf Setup

    The launcher resolves the signed Nightly component feed and installs the suite.

  2. 02

    Approve the agent filesystem

    Windows asks once for administrator approval while WinFsp is installed.

  3. 03

    Create the local owner

    Your RedLeaf account and agent workspace stay on this machine.

  4. 04

    Connect an AI provider

    Choose an available provider, complete its sign-in flow, and open your first Nova discussion.

Before you install

Requirements and dependencies.

Windows x64

The current public build target.

Internet access

Used to download components and sign in to your AI provider.

Administrator approval

Required once for WinFsp, which provides agent workspace drives.

AI provider account

Use the credentials and sign-in flow for the supported provider you choose.

Git for Windows

Required when Code inspects local repositories. RedLeaf does not currently install Git.

Preview warning

The launcher is not publisher-signed yet, so SmartScreen can show “Unknown publisher.”
